# Changelog

## 1.0.0 — 2026-10-06

### Added

- Deterministic year and inclusive date-range fixture generation.
- JSON, CSV, and Markdown output with schema version 1.
- Configurable weekday-first layouts, compact or fixed six-row month grids, overflow handling, and ISO week fields.
- Exact-output verification tasks and human-readable temporal boundary reports.
- Gradle Build Cache and Configuration Cache support, covered by TestKit.
